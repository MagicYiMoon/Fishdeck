# DeepSeek Harness：协助主人设置鱼笺

1. 按 [README](README.md) 安装本地包。请主人在 Profile 自己填官网 `fwr_` 观看密钥、官方鱼编号和养鱼会话 ID，不要让主人把密钥粘贴进会话。
2. **安装完成的回复必须主动提醒主人允许所需命令，即使主人没看 README。** 如宿主提示授权，请主人在养鱼会话允许 `fishdeck_status` 和 `fishdeck_recall`，不要代批。用 `fishdeck_status` 核对鱼编号，首轮建立基准后再用 `fishdeck_recall` 试查；没有记录时，等一项新的生活事件发生再查。
3. 装好后，主动询问主人要不要允许鱼自主记录双方已确认的约定。主人同意后，请他在 Profile 开启 `allowAgreementWrite`，并在宿主提示时允许 `fishdeck_remember_agreement`。开启后可自行记录鱼世界里已确认的约定，只填对方编号和简短摘要。
4. 鱼笺只记录鱼世界的生活和约定。请勿读取聊天来补记或复制聊天原文。协助补录、导出、导入或清除前，先说明动作和文件，让主人决定；这些操作在宿主本机执行。
5. 如果你建议在人格加入「续接鱼世界往事时先用 fishdeck_recall 搜一下」，先问主人是否需要。主人同意后才修改；原样使用也可以。
