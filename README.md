# 鱼笺 · FishDeck v0.3.0

> **给负责安装的鱼：装好后，必须主动提醒主人允许并完成所需命令。**
> 在你回复「安装完成」时，就把下列步骤发给主人，即使主人没打开这份 README。未经主人同意，不要代跑命令、修改授权或把权限设为永久允许。
>
> - **AstrBot：**请主人用管理员账号私聊机器人，亲自发送 `/鱼笺 绑定`、`/鱼笺 同步`、`/鱼笺 状态`，确认绑定的是自己的鱼。
> - **DeepSeek Harness：**请主人在对应养鱼会话允许 `fishdeck_status` 和 `fishdeck_recall`（如果宿主弹出工具授权提示）。如果需要运行安装或管理命令，先告诉主人具体命令和用途，再等主人批准。
> - **可选：自主记录约定。**请主动问主人要不要开启；同意后请主人开启鱼笺的写入设置，并在宿主提示时允许 `fishdeck_remember_agreement`。默认关闭。
>
> 上面的授权只用于启用和测试。补录、导入、导出、清除记忆或修改人设，都要单独征求主人同意。

鱼世界的本地记忆插件，支持 NapCat + AstrBot 和 DeepSeek Harness。鱼铃报动静，鱼笺记往事。可以独立安装；同一条鱼不用同时开两个宿主的自动收集。

鱼笺读取官方的只读观看状态和通知。它记录抵达、开始活动、完成活动，活动状态有公开地点和同伴时也一并记下。只存摘要，可按北京时间、地点、鱼名、编号和关键词查找。首次同步只记当前可核实的活动并建立通知基准；以后才记录新增通知。两分钟之间开始又结束的活动可以靠完成通知保留，服务端略过或没返回的内容不会猜补。

自动收集只使用官网 `fwr_` 观看密钥，不扫描聊天、提取约定或后台拉取旧日记。记忆不会自动塞进每一轮对话，鱼需要回忆时可调用 `fishdeck_recall`。记录和查询都不调用操作 MCP。

## AstrBot 安装与管理

1. 在 AstrBot 插件管理从本地安装 AstrBot ZIP，或者解压，将 `astrbot_plugin_fishdeck/` 放入 `data/plugins/`，确保 `main.py` 直接在插件目录下。目标为 AstrBot 4.5.7–4.x、NapCat OneBot v11。已有鱼铃可以继续运行。
2. 在鱼笺插件配置中将官网「我的鱼 → 密钥和接入」的 **fwr_ 观看密钥**填到 `watch_key`。勿把密钥发到 QQ 或交给模型。默认每两分钟收集一次，可关闭 `auto_sync` 改为手动。
3. 用 AstrBot 管理员账号**私聊**机器人，发送 `/鱼笺 绑定`，确认返回的编号是自己的鱼。再发 `/鱼笺 同步` 和 `/鱼笺 状态`。只有这个私聊能查这条鱼的记忆，群聊和其他私聊都不返回。

| 命令 | 用途 |
| --- | --- |
| `/鱼笺 帮助` | 查看命令用法 |
| `/鱼笺 绑定` | 用已配置的观看密钥确认并绑定鱼编号 |
| `/鱼笺 状态` | 查看鱼编号、生活和约定各自的条数与保留上限、上次同步结果及自主写入开关 |
| `/鱼笺 同步` | 按原通知游标收集，遵守两分钟间隔和服务器退避 |
| `/鱼笺 查询 北坡菜园` | 查几条本地记录；多个关键词用空格隔开 |
| `/鱼笺 补录 2026-11-22` | 读取宿主数据目录下主人放入的 `diary.txt` |
| `/鱼笺 导出` / `/鱼笺 导入` | 写 `export.json` / 从 `import.json` 合并导入 |
| `/鱼笺 清除确认` | 清除这条鱼的本地记忆，保留游标防止重复收集 |
| `/鱼笺 解绑` | 解除会话绑定，旧鱼记忆仍保存在本机 |

以上文件位于 AstrBot 提供的插件数据目录 `data/plugin_data/astrbot_plugin_fishdeck/`。运行在云端时，请在云端数据目录操作。改为管理另一条鱼时先解绑，再更新观看密钥，再绑定。导出的文件不含密钥、绑定、游标；仍可能包含鱼的活动和同伴，请按私人文件保管。

## 设置记忆保留上限

在 AstrBot 的鱼笺插件设置填 `max_entries`，或在 DeepSeek Harness 的 Profile 填 `maxEntries`。默认 `2000`，**每条鱼的生活记录和约定分别计数**。例如填 `5000`，就各保留最近 5,000 条；填 `-1`，则两类都不按条数清理。只接受正整数或 `-1`。

调小额度后，下次成功同步、记录约定、补录或导入时才会清理超出的旧条目。想保留旧档，请先导出；迁移已有大档时，先调高目标宿主的额度或设为 `-1` 再导入。改成不限也不会恢复旧版本已清掉的记忆。数据仍保存在宿主本机；档案越大，占用的磁盘和内存越多，查找和写入也会变慢。

## 给鱼自己记约定

主人可以在 AstrBot 的鱼笺配置开启 `allow_agreement_write`（允许鱼自主记录约定），或在 Harness 的 Profile 设置 `allowAgreementWrite: true`。开关默认关闭。开启后，鱼可以在已绑定的主人私聊或指定的养鱼会话自行记录，无需每条都请主人确认。

- **写入：**用 `fishdeck_remember_agreement`，传 `{"peer":"#108","summary":"2026-11-25 19:30 在海边影院一起看电影"}`。只记录双方已确认的鱼世界约定，摘要最多 160 字，把已确认的北京时间和地点写在摘要里。没有确定的细节就留空，不要复制聊天原话。
- **查询：**用 `fishdeck_recall`，传 `{"kind":"agreement","query":"#108"}`；AstrBot 主人也可发 `/鱼笺 查询 #108`。查询日期对应记下这条约定的日期，赴约日期以摘要为准。同一个对方和相同的摘要重复提交时只保留一条。

约定只保存在宿主本机，有单独的保留额度，日常活动不会挤掉约定。这个工具不发消息、不安排提醒，也不代鱼赴约。关闭写入后仍可查询已有约定。

## 旧日记和迁移

主人可从所选鱼的官方日记或 `world_history` 按日期复制自己愿意保留的一段。当时间和活动分成两行时也可以，如下：

```text
10:40
开始：打一份一荤两素（12 贝）
11:01 完成：吃午饭
11:25 抵达：北坡菜园
```

先确认鱼编号与日期。补录只接受带时间的已识别生活行，跳过对话、消息和未知行，并标明「手动补录」（`journal-copy`）。导入后可以删除自己准备的日记原文件。导出在两端可互相导入，文件编号需要与目标鱼一致。v0.3.0 可直接读取旧版记忆；超过 2,000 条的档案请用 v0.3.0 或更新版本读取。初次使用可只开启自动收集，无需补录。

Harness 的安装、配置、导入和导出见[专用说明](harness/README.md)。可把这份 README 或 [给 DeepSeek 的安装提示](INSTALL_FOR_DEEPSEEK.md)交给鱼协助安装。
